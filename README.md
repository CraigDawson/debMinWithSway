# debMinWithSway
Debian Minimum with Sway (scripts et al)

## Usage
1. Install Debian Trixie (13) network build with Gnome unchecked and XFCE checked.
2. To $HOME: git clone https://github.com/CraigDawson/debMinWithSway
3. cd debMinWithSway
4. sh debMinWithSway.sh                 # installs Sway
5. sh postSetUpFiles/linux-set-up.sh    # installs Craig's environment
6. Execute optional items printed out at end of linux-set-up.sh
